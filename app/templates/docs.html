Quickstart

Every tool follows the same four-step workflow. There is no account, no sign-up, and no limit on how many documents you process.

  1. Step 1

    Upload

    Drag files onto the drop zone, or click to browse. The file type and size are validated before anything else happens.

  2. Step 2

    Configure

    Set the options the tool needs (page ranges, passwords, watermark text). Only the fields relevant to that tool are shown.

  3. Step 3

    Process

    Click Process. The job is queued, processed on the server, and validated before you're offered a download.

  4. Step 4

    Download

    Download the result. Files are removed from our servers after {{ retention_seconds // 60 }} minutes — save yours before then.

Privacy & file handling

  • Uploaded files are stored in a private temporary directory on our infrastructure — inaccessible over the web.
  • Files are removed automatically {{ retention_seconds // 60 }} minutes after a job completes.
  • Passwords and document contents are never written to logs.
  • No documents are sent to external conversion or AI providers — everything runs on our own servers.

See the Privacy page for the full details.

Common issues

“The file does not appear to be a valid PDF”

The file's magic bytes don't match %PDF-. This usually means the file is not really a PDF (renamed from another format), or it's corrupted. Open it in a PDF viewer to check.

Merge with a single file returns an error

Merge requires at least two PDFs — otherwise there is nothing to merge. Upload a second file to enable the Process button.

Unlock says my password is wrong

Unlock only works when you supply the correct password — it is not a password recovery tool. If you don't know the password, the file cannot be opened.

PDF-to-Excel says no tables were detected

Table detection is heuristic. It works best on text-based PDFs with ruled tables. Scanned PDFs need the OCR tool first. PDFs laid out as free-flowing text with no table structure will not produce a spreadsheet — that's a limitation of the format, not a bug.

The download link has disappeared

Files are removed {{ retention_seconds // 60 }} minutes after the job completes. If you need the file again after that, re-upload and re-process — this is the trade-off for not keeping your documents on our servers.

A tool says it's not available on this server

Some tools require native binaries (LibreOffice, Tesseract, OCRmyPDF) or optional Python packages. When the underlying dependency is missing, the tool page shows a red notice instead of a broken upload form. Ask the administrator to install the required component, or open an issue on GitHub.
