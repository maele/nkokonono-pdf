About Nkokonono

Nkokonono ea PDF is a free, open-source PDF utility platform built with Flask and modern web standards. It handles the everyday PDF work — merging, splitting, compressing, converting, and organising — without sending your documents to a third-party service.

Private by design

Every uploaded file is stored locally in a private temporary directory on our infrastructure, is inaccessible over the web, and is automatically removed according to our retention policy. Passwords and document contents are never logged.

Open source

Nkokonono is open source under the MIT licence. Inspect the code, run it on your own infrastructure, contribute fixes, or verify the security claims above for yourself.

View source on GitHub

Built on Python

Nkokonono is built on a modular Flask backend. Each tool is implemented as an independent processor that can be tested on its own — inspect the code to see exactly what each operation does, with no black boxes.
